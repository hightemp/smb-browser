# Linux packaging

This document describes the first Linux packaging profile for SMB Browser.

## Target

- Primary package format: Debian package generated by CPack.
- Baseline distro for the current profile: Ubuntu 22.04.
- UI runtime: Qt5 Widgets.
- Secret storage runtime: QtKeychain with the platform keychain backend.
- SMB backend: built-in clean-room native SMB2/SMB3 engine.

## Build package

Default CI/package smoke profile builds the native SMB backend and does not
download or link `libsmb2`.

```bash
make package-linux
ctest --test-dir tmp/package-linux --output-on-failure
make smoke-linux
```

The generated `.deb` is written to `tmp/package-linux/packages`.

## Runtime dependencies

The DEB profile declares the baseline runtime packages:

- `libqt5core5a`
- `libqt5gui5`
- `libqt5widgets5`
- `libqt5sql5`
- `libqt5sql5-sqlite`
- `libqt5svg5`
- `libqt5keychain1`
- `libsodium23`

The Linux package smoke script rejects `libsmb2`, `smbclient` and Samba CLI
runtime dependencies in both package metadata and executable linkage. The legacy
`libsmb2` backend can be enabled only through explicit development CMake flags
and is not part of the default package profile.

## Installed files

The current install profile installs:

- `smb-browser` binary into the standard binary directory.
- Russian translation file into `share/smb-browser/i18n`.
- Desktop entry into `share/applications`.
- AppStream metainfo into `share/metainfo`.
- Application icon into `share/icons/hicolor/scalable/apps`.

`LocalizationManager` searches `../share/smb-browser/i18n` relative to the
installed binary, so packaged English/Russian UI switching can find the `.qm`
file.

## Secret storage notes

QtKeychain delegates to the platform keychain backend. On Linux this usually
means Secret Service or KWallet, depending on the desktop environment.

Known release checks:

- Test under a normal graphical session, not only in a headless container.
- Verify that saving and reading credentials works after application restart.
- Verify behavior when no Secret Service/KWallet backend is running.
- Verify that fallback encrypted vault messaging is clear if keychain storage
  is unavailable.

## Manual smoke

Before publishing a Linux package:

1. Install the generated `.deb` on the target distro.
2. Start `smb-browser` from the desktop menu and from a terminal.
3. Switch language to Russian and confirm translated UI text loads.
4. Add/edit/delete a connection.
5. Save and reload a synthetic credential.
6. Connect to a test Samba server and list a directory through the native
   backend.
7. Run the optional Docker Samba integration profile on a prepared Linux host.
